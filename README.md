# Team ASAP Home Improvement — website

Production website for Team ASAP Home Improvement LLC (New Rochelle, NY). Built by Dalal Technologies.

## What this is

A fast, static multi-page site generated by one Python script with no dependencies. It deploys on Netlify, and Netlify Forms handles quote submissions, photo uploads, spam filtering and email notifications.

```
content/site.json      business details: phone, owner, trust figures, service areas, analytics, review mode
content/services.json  all service page copy (9 pages)
content/projects.json  the portfolio: add or edit projects here
assets/                site.css, site.js, img/ (project photos + labeled illustrations), brand/ (logos, icons)
build.py               generator: python3 build.py -> public/   |   python3 build.py --preview -> preview/
netlify.toml           build command, publish folder, security and cache headers
```

### Pages
Home, Plumbing (hub), Leak detection & pipe repair, Drain & sewer, Water heaters, Fixtures & installation, Emergency plumbing, Home improvements (hub), Bathroom remodeling, Our work, About, Contact (multi-step quote), Privacy, 404. Plus sitemap.xml and robots.txt.

## Deploy (GitHub + Netlify)

1. Create a GitHub repo (e.g. `alioune378/team-asap-site`) and push this folder.
2. In Netlify: **Add new site → Import from Git →** pick the repo. Netlify reads `netlify.toml` (build `python3 build.py`, publish `public`).
3. **Forms:** Netlify detects the `quote` form automatically on the first deploy. Then go to **Site configuration → Forms → Form notifications → Add notification → Email** and enter the owner's email. Submissions, including photos, also appear under the Forms tab.
4. **Domain:** add the custom domain under **Domain management**, then set `siteUrl` in `content/site.json` to the final domain and push. This updates canonical URLs, Open Graph tags, sitemap and schema.
5. **Google Search Console:** verify the domain and submit `https://<domain>/sitemap.xml`.
6. **Google Business Profile:** set the website field to the new domain.

## Editing content

- **Add a project:** drop photos (JPG/WebP, ideally 1600px+ wide) into `assets/img/`, add an entry in `content/projects.json` with `"published": true`, then commit. Netlify rebuilds automatically.
- **Change the phone, service towns or trust figures:** edit `content/site.json`.
- **Flip launch switches in `content/site.json`:**
  - `reviewMode: false` hides the "Owner review" button
  - `freeEstimates: true` changes every CTA to "Get a Free Quote" (only if confirmed)
  - `emergency247: false` removes 24/7 wording everywhere
  - `analytics.ga4Id` turns on GA4 with a consent banner

## Analytics events

Sent to `dataLayer` (and GA4 when configured): `call_click`, `emergency_call_click`, `quote_cta`, `quote_form_start`, `quote_step_view`, `quote_photos_added`, `quote_form_submit`, `quote_form_error`, `portfolio_open`, `portfolio_filter`, `reviews_click`. Each event includes `location` and `page`. In GA4, mark `quote_form_submit`, `call_click` and `emergency_call_click` as key events.

**Referral tracking:** give partners links like `https://<domain>/?utm_source=partner-name&utm_medium=referral`. The UTM tags, landing page and referrer are saved with each quote submission, so the owner can see which partner sent each lead.

### Stack choice

The brief suggested Next.js. This build uses a static generator instead. That matches the existing GitHub + Netlify workflow, has no framework to maintain, loads faster, and gets real form handling from Netlify without a custom backend. The trade-off is that there is no admin dashboard: content is edited in JSON files. Moving to Next.js later is straightforward because content is already separated from templates.
